# SPEC-02｜離線時間推進與健康救援引擎

> **導覽：** [← 回到規格入口](../README.md) ｜ [Phase A 規格地圖](../PHASE-A-SPEC-MAP.md#spec-02) ｜ [Master PRD v2.1.31](../../PRD/AI_虛擬桌寵專案規格與需求書%20%28Master%20PRD%29.md) ｜ [ROADMAP](../../../ROADMAP.md)

## 1. 這個 SPEC 的目的是什麼？

落實拾暖最核心的兩大產品承諾：
1. **極致省電（免背景常駐）：** 玩家關掉 App 甚至出差幾天再打開時，只靠最後時間戳 `lastSimulatedAt` 精準補算所有日夜需求與健康變化，而且**「一次補算 24 小時」跟「每隔幾小時打開一次」結果分毫不差（誤差 `< 1e-9`）**。
2. **無壓力陪伴底線（絕不死貓、不逼課金）：** 透過「低心情 40 健康安全地板」、「飢餓缺水 10 健康保護下限」、「2 小時急速脫險 Boost」、「分級自然恢復」與「無懲罰照護暫停 Care Pause」，讓忙碌的上班族就算忘了照顧，回來也能溫柔把貓救回滿血。

---

## 2. 要完成哪些功能？

### In-Scope（本 SPEC 涵蓋）
- **日夜作息與時區感知時間引擎：** 依外部注入的裝置時區換算本地日夜（日間 `07:00~23:00` 衰退係數 `1.0`、夜間 `23:00~07:00` 係數 `0.3`）、跨本地午夜自動遞增累計天數 `ageInDays`、偵測裝置時鐘回撥時自動保護不暴扣。
- **精確交點切割引擎：** 遇到日夜邊界、需求跌破 20／50／60、心情跨越 70／40／20、低心情累積滿 72h／48h、健康撞到 40 地板／10 下限／100 滿血、或 2 小時 Boost 用滿時，自動精準切段計算。
- **混合健康懲罰保護：** 短期沒陪玩只扣心情不扣血；唯有長期連續低心情才啟動極緩慢扣血且嚴格停在 `40` 安全地板（絕不會把貓推入 `CRITICAL`）；飢餓／缺水扣血嚴格停在 `10` 下限（永不死亡）。
- **四態健康救援狀態機與 Care Pause：** 完整支援 `NORMAL → CRITICAL → RECOVERY_BOOST (+10/hr, 上限 2h) → NATURAL_RECOVERY (+2.5/+1.25/0, 夜間照常回血) → 滿血 100 重置`，以及一鍵開啟／解除零懲罰暫停模式。
- **時間模擬看板（`apps/local-sandbox` Tab 2）：** 快轉時間按鈕、四大血條、日夜背景、一鍵演練「3 天未登入 → 進危急 → 2 小時急速救援 → 滿血復活」與 Care Pause 凍結開關。

### Out-of-Scope（明確排除）
- 不發放跨日高健康積分獎勵、不處理買賣與背包消耗（交由 `SPEC-03`）。
- 不實作存檔寫入磁碟（`TC-MH-11` 存檔續算交由 `SPEC-03` `S3-02`）與動畫行為仲裁（交由 `SPEC-04`）。

## 3. 對應 Master PRD 哪幾點？

- **[Master PRD v2.1.31](../../PRD/AI_虛擬桌寵專案規格與需求書%20%28Master%20PRD%29.md) §1 核心產品承諾：** 無死亡、健康下限 `10`、無懲罰 `CarePause`。
- **§4.2 時間差模擬與照護暫停保護：** 0.25h 基礎步長、日夜切割、開啟與解除暫停規則。
- **§8.C.1 時間步進計算順序與日夜區段公式：** 全部衰退速率、Signed Rate 交點公式、`VALUE_EPSILON` / `TIME_EPSILON_MS`、`MoodHealthPenalty` 40 安全地板、4 態 `RecoveryState` 與 P1-4 指令後即時重評。
- **§10.2 #2 系統時間倒退異常：** 時鐘回撥時 `Δt = 0`、不覆寫 `lastSimulatedAt` 並記錄異常事件。
- **§8.E.2 / §8.E.3 自動化驗收劇本：** `TC-03`、`TC-04`、`TC-MH-01`～`TC-MH-10`、`TC-MH-12`。
